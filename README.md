The Australian Taxation Office (ATO) is the Australian Government's principal revenue collection agency, administering the tax and superannuation systems. Through the ATO API Portal (apiportal.ato.gov.au) it gives digital service providers (DSPs) an API product catalogue with documentation and subscriptions, listing APIs such as SMSF Alias Lookup, the Digital Services Gateway Health Check, Stapled Super Fund, OAuth Dynamic Client Registration, Global and Domestic Minimum Tax lodgment and the GST Property Settlement Service.

**Areas:** Company · Government · Taxation · Superannuation · Australia · Digital Service Providers · Public Sector

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Australian Taxation Office: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
